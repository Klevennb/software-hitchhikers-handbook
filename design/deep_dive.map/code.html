METHOD: Array.prototype.map()

WHAT IT DOES

ID: 0xFF452

The map() method creates a new array populated with the results of calling a provided function on every element in the calling array.

check_circle

IMMUTABILITY

Does not mutate the original array; returns a fresh instance.

transform

ONE-TO-ONE

Maintains the exact same length as the source array.

01 // WHAT_IT_IS

REF_ID: 0x4F2A

The Factory Method is a creational design pattern that provides an interface for creating objects in a superclass, but allows subclasses to alter the type of objects that will be created. It solves the problem of creating product objects without specifying their concrete classes.

INTENT

Define an interface for creating an object, but let subclasses decide which class to instantiate.

ALIAS

Virtual Constructor

  • Open/Closed Principle adherence
  • Single Responsibility Principle

interface Button {
    render(): void;
    onClick(f: Function): void;
}

class WindowsButton implements Button {
    render() { console.log("Rendering a Win-style button."); }
}

class HTMLButton implements Button {
    render() { console.log("Rendering a HTML-style button."); }
}

abstract class Dialog {
    public abstract createButton(): Button;

    render() {
        const okButton = this.createButton();
        okButton.render();
    }
}

class WindowsDialog extends Dialog {
    createButton() { return new WindowsButton(); }
}
